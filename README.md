

# 🌤️ Projeto Clima

Este é um projeto simples de previsão do tempo desenvolvido para uma atividade escolar. Ele utiliza uma **API de clima**, **JavaScript** e **JSON** para buscar e exibir as informações meteorológicas de uma cidade escolhida pelo usuário.

## 📦 Como funciona

1. O usuário digita o nome de uma cidade.
2. O site faz uma requisição à API de clima.
3. Os dados retornam em formato JSON.
4. O JavaScript interpreta os dados e exibe na tela:
   - Temperatura atual
   - Condição do tempo (ensolarado, nublado, etc.)
   - Velocidade do vento
   - Ícone do clima
